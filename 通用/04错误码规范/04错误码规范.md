# 错误码规范

> 适用范围：所有对外接口的统一返回体。核心原则：**错误码按模块分段、枚举按模块隔离**。

## 一、错误码分段登记

| 段位 | 归属 | 枚举类 | 所在模块 |
|---|---|---|---|
| 4xx / 5xx | 通用语义（参数、认证、系统异常） | `CommonResultCodeEnum` | `common` |
| 10xxxx | 用户模块 | `UserCodeEnum` | `module-user` |
| 12xxxx | 考试模块 | `ExamCodeEnum` | `module-exam` |
| 13xxxx+ | 待分配，新增模块在此表登记 | — | — |

- 通用段沿用 HTTP 语义码值（400 / 401 / 403 / 404 / 500），便于前端和网关统一识别，**不在此段放业务错误**。
- 业务错误一律使用六位码，前两位为模块号，后四位为模块内序号。
- 模块之间互不占用号段，新增模块先登记再开发，避免码值冲突。

## 二、枚举组织：公共枚举 + 模块独立枚举

### 2.1 目录结构

```
common
└── enums
    └── CommonResultCodeEnum.java   // 公共错误码 400/401/500 这一类
module-user
└── enums
    └── UserCodeEnum.java           // 用户模块 10xxxx
module-exam
└── enums
    └── ExamCodeEnum.java           // 考试模块 12xxxx
```

统一返回对象 `Result<T>` 放在 `common`，**接收一个接口，而不是固定枚举**。

### 2.2 统一接口

```java
public interface IResultCode {
    Integer getCode();
    String getMsg();
}
```

### 2.3 公共枚举

```java
public enum CommonResultCodeEnum implements IResultCode {
    PARAM_ERROR(400, "参数错误"),
    UNAUTHORIZED(401, "未认证或登录已过期"),
    FORBIDDEN(403, "无访问权限"),
    NOT_FOUND(404, "资源不存在"),
    SYSTEM_ERROR(500, "系统内部错误");

    private final Integer code;
    private final String msg;

    CommonResultCodeEnum(Integer code, String msg) {
        this.code = code;
        this.msg = msg;
    }

    @Override
    public Integer getCode() {
        return code;
    }

    @Override
    public String getMsg() {
        return msg;
    }
}
```

> 若项目已引入 Lombok，可用 `@Getter` + `@AllArgsConstructor` 消除各枚举中重复的构造器和 getter。

### 2.4 模块枚举

```java
public enum UserCodeEnum implements IResultCode {
    USER_NOT_EXIST(100001, "用户不存在"),
    USER_DISABLED(100002, "用户已被禁用");

    // 构造器与 getter 同上
}
```

```java
public enum ExamCodeEnum implements IResultCode {
    EXAM_NOT_EXIST(120001, "考试不存在");

    // 构造器与 getter 同上
}
```

### 2.5 统一返回对象

```java
public class Result<T> {
    private Integer code;
    private String msg;
    private T data;

    // 关键：入参是接口而非某个具体枚举
    public static <T> Result<T> fail(IResultCode resultCode) {
        return fail(resultCode.getCode(), resultCode.getMsg());
    }

    public static <T> Result<T> fail(Integer code, String msg) {
        // 组装失败响应
    }

    public static <T> Result<T> ok(T data) {
        // 组装成功响应
    }
}
```

### 2.6 调用方式

```java
return Result.fail(UserCodeEnum.USER_NOT_EXIST);
return Result.fail(CommonResultCodeEnum.PARAM_ERROR);
return Result.fail(ExamCodeEnum.EXAM_NOT_EXIST);
```

## 三、落地约束

1. `Result` 只依赖 `IResultCode`，**不得反向依赖任何模块的枚举**，否则 `common` 会被业务模块污染。
2. 业务枚举只在自己的模块内定义与使用，跨模块调用走公共码或各自的 Service 出口。
3. 新增码值只允许在所属模块的枚举末尾追加，**不复用、不修改已发布的码值**，避免前端映射错乱。
4. 同一含义在公共段已有码值时复用，不再于模块段重复定义。

## 四、新增模块接入步骤

1. 在上方「错误码分段登记」表里申请一个新段位（如 `14xxxx`）。
2. 在该模块 `enums` 包下新建 `XxxCodeEnum implements IResultCode`。
3. 按同一模板补齐构造器与 getter，码值从段位起点递增。
4. 返回时统一走 `Result.fail(XxxCodeEnum.YYY)`。
