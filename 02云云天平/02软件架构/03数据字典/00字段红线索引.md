# 字段红线索引

> 只收「不知道就会写错代码」的字段。完整表结构用 `SHOW FULL COLUMNS`，这里不重复。
> 每条都注明**踩过的具体后果**，没有后果的字段不进这张表。

## 一、`question`（题库主表，28 列）

| 字段 | 类型 | 真实含义 | 🔴 红线 |
|---|---|---|---|
| `score` | **varchar** | 单题分值 | **两侧类型不一致**：`manage` 按 `String`、`exam-service` 按 `BigDecimal`；`convertToQuestion` 零校验 → 非数字串能入库 → **开考取卷 500**。取卷 500 先全库扫 `score NOT REGEXP '^[0-9]+([.][0-9]+)?$'` |
| `option_content` | **json** | 本题选项 `{"A":"…"}` | `WHERE option_content=%s` **永不命中**，见 [[02改库红线与五闸门]] §4.1 |
| `content` | text | 题目标题 | 与 `passage` 的落点**按题型相反**，见 §二 |
| `passage` | text | 题目内容（材料/主干） | 同上 |
| `answer` | text | 参考答案 | 成篇写作与笔译有 **71 条是占位「略/（略）」**，不能当评分依据 |
| `number` | Integer | 题号 | `0` = 例题；分组行在 Excel 里是空，落库后按区间展开 |
| `type_id_mapping` | varchar | **题型编码**（英文） | 字段名**不是** `type_mapping_id`；字典真源 `common/.../enums/QuestionType.java`；CSCA 1,904 条为空是**设计如此** |
| `exam_layout` | varchar(32) | 考试渲染布局，**8 值** | 尚未落库实施（`Question` 实体无此字段）；见 [[题库-考试布局字段]] |
| `layout` | varchar(32) | **练习侧老分族字段** | 🔴 **不要复用、不要改值域**，见 §三 |
| `group_id` | bigint | 题组 id | 🔴 老批次（HSK2.0 L1~L4）为 **NULL**，按组取材料不能只写 `q.group_id`，见 §四 |
| `section` | varchar | 卷内板块序号 | 多模块共用，**判断模块只能用 `section_mapping`** |
| `section_mapping` | varchar | `SEC_LISTEN` / `SEC_READ` / `SEC_WRITE` | 「书写」`handwriting_*` 与「写作」`writing_*` 都落 `SEC_WRITE`，统计**别合并** |
| `type_id` | varchar | 题型中文名 | 例题的 `type_id` 就是「例题」，真实题型要取同卷同组正题众数 |
| `audio_url` | varchar | 例题专用音频 | ★ 普通题为空是 **by design**，听力音频是整卷单文件 |

## 二、`content` 与 `passage` 的落点（例题与正题相反）

| | `content` | `passage` |
|---|---|---|
| **正题** | 放问题 | 空（或材料） |
| **例题** | **留空** | 放问题（`★` 起头那几行） |

🔴 改例题时把问题塞回 `content` → 界面重复显示两遍。判据：`number=0 AND section_title='例题'`（与 `type_id_mapping='example_question'` 实测等价）。

## 三、`question.layout` —— 练习侧老字段，动它等于动练习

| 项 | 实测 |
|---|---|
| 定义 | `varchar(32)`，comment「题型」 |
| 老值 | `textChoice` 4,263 / `textChoice_shareAudio` 945 / `passageGroup` 522 / `textJudge` 400 / `imageMatch` 375 / `imageJudge` 300 / `clozeGroup` 150 / `imageChoice` 130 |
| 空值 | **NULL 6,539（48%）** |
| 谁在写 | `manage` 侧 **grep 零命中**，值全是历史数据 |
| 谁在读 | `practice-service` 听力模块 **4 处** |

🔴 4 处依赖（改值域会静默失效）：

| 位置 | 用途 | 换值域后的后果 |
|---|---|---|
| `ListeningRecordServiceImpl:343`、`ListeningSubmissionFinalizer:437` | `needsSharedAudioByLayout()` 判 `textChoice_shareAudio`/`passageGroup` 才下发 `shareAudioUrl` | 恒 false → **听力细节题丢共享音频** |
| `ListeningReportServiceImpl:380`、`ListeningSubmissionFinalizer:451` | 报告题型中文名 switch | 报告题型空白 |
| `ListeningSubmissionFinalizer:458` | `deriveVariant()` 白名单 → short/long/interview | 变体全丢 |

共享音频真源是 `question_shared_audio`（**237 行，按 `group_id` 键**），本来就不该靠 layout 冗余标记。要做统一布局字段，先解绑这三处。

## 四、`question_group`

| 字段 | 坑 |
|---|---|
| `question_group` | 🔴 老批次**整列为 NULL**；有值的是题号区间串（`1-5`）。按组关联必须双路：`g.paper_id=q.paper_id AND CONCAT(g.start_number,'-',g.end_number)=q.question_group` |
| `passage` | 题组级材料（阅读长文、段落拼图、带空标记段落） |
| `option_content` | 题组级选项池：`reading_sent_fill` 句池、`reading_para_sort` 字母池。**本题侧的同名字段是 NULL 或副本** |
| `audio_url` | 听力共享音频（按题号 seek，不是每段独立文件） |

## 五、作答侧

| 表.字段 | 红线 |
|---|---|
| `practice_answer`（三份快照） | 🔴 **答题/复习页的数据源是快照**，改 `question` 对历史答卷**不生效**；快照里有 `"score":"1.25"`，**禁止整串正则替换** |
| `writing_answer.answer_type` | 只有 4 个**文本**枚举：`TOKEN_SEQUENCE` / `TEXT_SINGLE_GRAPHEME` / `TEXT` / `SUMMARY`。**没有 AUDIO / IMAGE** → 写单字只存一个字，不存笔迹（`WritingAnswerServiceImpl:280` 校验 `count > 1 → 400`） |
| `exam_record.current_question_number` | 续考落点**唯一来源**；禁止整对象 `updateById`（会覆盖其它字段） |
| `exam_record.duration` | 含超时懒闭卷的时间，**对外一律 `capCscaDuration` 封顶**；历史值禁改禁修 |
| `user_exam_quota` | 唯一键**含 `level`**：给 HSK 加次数必须加在 `version='HSK2.0'` 那行，加到别处无效 |

## 六、`level` 字段（HSK 7-9 专项）

- 7-9 是**一个**等级，`question`/`practice` 侧值统一写 `7`
- **卷侧**（`exam_paper.level`）写的是 `'7-9'`
- 🔴 `getLevel()` **不能 `Integer.parseInt`** → 抛 `NumberFormatException`；`exam-service` 仍有 5 处老写法（`ExamRecordServiceImpl` 3 处 + `HskExamEndJobHandler:86`）
- 取卷是 `a.level = #{level}` **等值比较** → 前端必须传 `'7-9'`，传 `7` 取不到
