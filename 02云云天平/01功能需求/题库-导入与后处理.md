# 题库-导入与后处理

## 背景

后台通过 Excel 批量导入 HSK / CSCA 题目。导入不是「读一行写一行」，链路里有一批**有损行为**和**必须补齐的后处理**，否则数据看起来进去了、实际不能用。

## 用户看到什么

1. 运营在后台选 Excel、点上传，得到「成功导入 N 题」或逐行错误清单；
2. 导入后题目能在题库列表按题型、按卷筛出来；
3. 导入后**能直接开考**（取卷不报错、题目渲染正常、分值是 100 分制）。

## 什么算对（验收标准）

| # | 判据 | 不合格的表现 |
|--:|---|---|
| 1 | 每卷题号连续、无重号 | 答题卡缺号 |
| 2 | 分值配平：HSK 每模块 100；CSCA 每卷 100 | 总分显示 99.84 / 399.36 |
| 3 | 题型编码全部命中字典（`type_id_mapping` 非 null） | 题型筛选查不到、练习取题为空 |
| 4 | 解析（`analysis`）是 HTML 片段 | 前端把 `<p>` 当纯文本显示 |
| 5 | 数学公式已矢量化 | 公式显示成乱码/半截 |
| 6 | 例题可定位、不计分 | 例题混进答题卡、被计分 |
| 7 | 取卷不 500 | 开考即报错 |

## 链路里的有损行为（改 Excel 无法规避）

| 行为 | 后果 |
|---|---|
| **全角标点强制转半角** | `，`→`,`、`。`→`.`、`……`→`..`、`〈〉`→`<>`（会破坏 HTML 渲染） |
| 第 17 列及以后静默丢弃 | 图片名称列白填，图片必须内联 |
| 不写 `layout` | 依赖 layout 的页面全空 |
| 不做 `analysis` HTML 化 | 解析显示成一行 |
| 听力题的 `score` / `answer` 被置 null | 按设计接受，听力计分走分组 |

> 上传前的自查清单见 [题库Excel上传格式校验规范](../03业务模块/manage/题库Excel上传格式校验规范.md)。

## CSCA 必做的 5 项后处理

导入完成后按顺序执行，缺一项就有可见缺陷：

1. `analysis` 包 `<p>` 标签
2. 公式矢量化（`analysis` / `passage` / `option_content` 三处）
3. `layout` 回填
4. `score` 配平到**每卷 100 分**
5. 题型抽检：`answer` 含 `,` 的必须是「多选」

## 已知约束

- 🔴 导入**只影响新题**：历史答卷走 `practice_answer` 的三份快照，改 `question` 不会回改历史答卷；
- 🔴 `score` 是 varchar，写进非数字串会在**开考取卷**时才 500，导入阶段不报错；
- 导入接口与字段定义见 [[00字段红线索引]]，链路细节见 Obsidian 外部代码注释（`QuestionExcelTemplate:77`）。
