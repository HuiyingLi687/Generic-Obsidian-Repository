# 变更台账

数据库变更按月记录，**回答一个问题：这个字段为什么在这儿**。

## 用法

每月一个文件，命名 `NNN-YYYY-MM.md`，放在本目录。当月有变更就新建或追加，没有就不建文件。

**`NNN` 是三位数倒序编号：越新的月份编号越小**，这样按名称升序排列时最新的一期永远在最上面。起始从 `999` 往下写，新增一个月就取当前最小号减一（10 月是 995，11 月就是 994）。

## 填写规则

1. **日期**省略年份，只写 `MM-DD`，年份由文件名的 `YYYY-MM` 段给出
2. **版本**跟 Flyway 对齐（`V1`、`V2`），未接入前写 `—`
3. **数据回填**不确定就写「待确认」，不要留空，留空看起来像已完成
4. **不写 SQL 正文**，只写表名和字段名；**不记线上执行状态**，那个查 `flyway_schema_history`

## 为什么按月分文件

变更天然是时间线，按月切分后：找某次上线只翻一个月；文件不会无限增长；当月只需改一个文件，不用在几百行里找位置。
