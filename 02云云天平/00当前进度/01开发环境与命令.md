## 二、构建

🔴 **IDEA 2026.2 不带 mvn 命令行**（`E:\idea\IntelliJ IDEA 2026.2.3\plugins\maven-plugin\lib` 里只有内核 jar，没有 `maven3/bin`），系统 PATH 也没有。两条路：

### 2.1 mvn 可用时（推荐）

```bash
JAVA_HOME="C:/Users/l/.jdks/ms-17.0.20.1" mvn -pl exam-service -am compile -DskipTests
```

- 命令行 mvn **必须显式** `JAVA_HOME=`，否则用默认 JDK 25 → Lombok 失效，报一堆「找不到 getter」
- 单模块走 reactor（`-pl xxx-service -am`），不要单独进子目录
- 单测：加 `-Dsurefire.failIfNoSpecifiedTests=false`（否则没有匹配测试就失败）
- `gateway` 有失效单测 → `package` 必加 `-DskipTests`
- 删过源码/资源 **必须清 `target`**，否则残留 class 会被打进包

### 2.2 只能用 javac 验型时

`.m2` 里 429 个 jar 拼 `-cp` 会超 32K 命令行上限 → **必须走 @argfile**：

```bash
# 参数文件已生成好
javac -encoding UTF-8 @tmp/args_common.txt      # common/src/main/java，38 文件
javac -encoding UTF-8 @tmp/args_exam.txt        # exam-service/src/main/java，206 文件
```

⚠️ **不要把 `target/classes` 当 classpath** —— 它可能是旧产物，会报莫名其妙的「找不到符号」。以源码为准。

## 三、端口与服务

| 服务 | 端口 | 备注 |
|---|---|---|
| gateway | **8080** | 生产网关端口 |
| exam-service | **8084** | 直连联调常用，可免网关 |
| 数据库 | 3306 | 见第四节 |

**直连 exam-service 联调**：`jwt.secret` 用代码默认值自签 HS256，⚠️ payload **必须带 `clientType`**；
不带 `X-Client-Type` 头 → **userId 恒为 1**（不是 401，这个更坑，会以为登录态正常）。

本机 `nacos discovery.enabled: false` → 跨服务调用 503；`start/csca` 会因 `AuthProfileClient` fail-closed 变 500（**不是 bug**）。

## 四、数据库连接

| 环境 | 地址 | 账号 | 注意 |
|---|---|---|---|
| TEST | `8.138.185.11:3306/xuexitest` | root / `szkjxy@hkbtest!` | **必须带** `ssl={'ssl':{}}` |


## 五、工具坑

| 现象 | 原因 | 对策 |
|---|---|---|
| PowerShell 工具看不到输出 | 本机不回传 stdout | 查端口/杀进程改走 **Bash**：`netstat -ano \| grep 8080`、`taskkill //PID <pid> //F`（Git Bash 用**双斜杠**） |
| Edge headless 截图失败 | 必须走 PowerShell | 截图类任务用 PowerShell 调 |
| `not enough arguments for format string` | pymysql 无参执行时传了空 tuple `()`，SQL 里又有 `LIKE '%…%'` | `cur.execute(sql)` 不传第二参 |
| `LIKE '%<img%'` 报格式错 | `%` 被当占位符 | 参数化，或写 `%%` |
| 服务间 HTTP 调用报 `0x16` | 调用方用了 `https://` | 全是**纯 HTTP** |
| MinIO 上传 403 | 两套地址 | `common` = `http://43.99.57.11:9000`（PROD）；`manage`/`system-service` = `http://www.hkbvvtb.com:9000`（TEST） |
| 构建报 `errno=1455` | 内存打满（上限 40–49G） | 走 mvn，别并发跑重编译 |
| `ModuleNotFoundError: pymysql` | 本机 Python（`.workbuddy/binaries/python/versions/3.13.12`）只装了 pillow | 先 `python -m pip install pymysql`；装完 `import pymysql` 验一下再跑脚本 |

## 六、排查顺序（接口「业务突然不生效」）

🔴 先查**路由有没有注册**，不要先怀疑业务逻辑：

```
Build 中断 → target/classes 缺包 → 路由未注册 → 请求落静态资源
→ NoResourceFoundException → 被兜底成 {"code":500} + HTTP 200
```

识别特征：**HTTP 200 但 code=500**、日志有 `NoResourceFoundException`。修完**重启服务**。
