# 汉考宝

> **AI 第一读**。读完这份再去 [当前进度](00当前进度/当前进度.md)，不要直接翻 `03业务模块/`。

## 这是什么

面向中文学习者的**多语种考试练习平台**，覆盖 CSCA（国际中文教师证书）、HSK（2.0 / 3.0）、课程。
后端是一套微服务，管理后台负责题库导入与试卷编排。

## 技术栈与代码仓库

| 项 | 内容 |
|---|---|
| 后端 | Spring Boot 3.5.6 / GraalVM JDK 21 |
| 持久层 | MyBatis Plus + Spring Data JDBC（HikariCP） |
| 数据库 | MySQL，**11 个服务共用同一个库 `xuexitest`**（73 张表） |
| 部署 | Docker Compose |
| 代码仓库 | 本地 `D:/code/hsk_treasure`（远程地址待补） |

## 关键约束

1. **返回体全局统一 `Result<T>`**（`code / msg / data / traceId`），公共码 200000/400000/401000/500000，模块码见 [错误码和统一返回体](../00当前仓库规范/编码规范/错误码规范/错误码和统一返回体.md)
2. **11 个服务共用一个库**，改表前必须查 [01表归属矩阵](02软件架构/02数据库/01表归属矩阵.md) 确认影响面
3. **题目数据必须过「统一检查点」才能上线**，见 manage 下的验收标准
4. **代码提交 ≠ 数据库已改**。改结构必须同时登记 [数据库变更台账](00当前进度/00数据库变更台账/)，两边对不上就是事故
