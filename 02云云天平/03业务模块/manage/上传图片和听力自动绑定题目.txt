同时上传excel和图片、音频，excel中一列是图片名称，根据图片名称列来绑定图片链接到字段中，所有命名遵循统一模板：`HSK{级别}_{试卷编号}_{定位信息}[_{选项}]`，
| 部分 | 说明 | 示例 |
|---|---|---|
| 级别 | HSK1–HSK6 | `HSK1` |
| 试卷编号 | 试卷编号（如从「来源」`HSK1_H11112` 取 `11112`） | `11112` |
| 定位信息 | 题号 / 题号范围 / 题型范围+例序号 | `6` / `1-5` / `1-5_例1` |
| 选项（可选） | 选项字母 A–F；例题的选项图形如 `例A`~`例F` | `_A` / `_例A` |
绑定规则如下：


1、若含有`[_{选项}]`，则绑定到question.option_content的对应选项中，格式为{
  "A": "<img src=\"<图片URL>\" style=\"max-width:100%;\">",
  "B": "<img src=\"<图片URL>\" style=\"max-width:100%;\">",
  "C": "<img src=\"<图片URL>\" style=\"max-width:100%;\">"
}
如：{"A": "<img src=\"http://www.hkbvvtb.com:9000/hsk/image/3232344/hsk-2062042676694003713/HSK1_10901_6_A-5f8e5a80-962d-49c4-af71-974eb4375310.jpeg\" style=\"max-width:100%;\">", "B": "<img src=\"http://www.hkbvvtb.com:9000/hsk/image/3232344/hsk-2062042676694003713/HSK1_10901_6_B-287af061-e4cb-4a06-9bf8-12bfcb052e86.jpeg\" style=\"max-width:100%;\">", "C": "<img src=\"http://www.hkbvvtb.com:9000/hsk/image/3232344/hsk-2062042676694003713/HSK1_10901_6_C-f56114fd-f4ed-44d5-ade4-88a5e68966d2.png\" style=\"max-width:100%;\">"}


2、若没有`[_{选项}]`，则绑定到question.passage中，但是这个字段中还有题目内容，需要把图片链接放在题目内容前，题目内容可以为空...格式为<img src="<图片URL>" style="max-width:100%;">题目内容...
如：<img src="http://www.hkbvvtb.com:9000/hsk/image/3232344/hsk-2062042676694003713/HSK5_51002_100-7ed70ef9-7184-4468-8e2e-972a8ff30537.jpeg" style="max-width:100%;">请根据这张图片写一篇80字左右的短文.


3、若是excel中题目序号为空的，这类题是题组，不会存在选项图，图片则绑定到question_group.passage中，但是这个字段中还有题目文章内容，需要把图片链接放在文章内容前，格式为<img src="<图片URL>" style="max-width:100%;"><p>文章内容</p>...
如：<img src="http://www.hkbvvtb.com:9000/hsk/image/3232344/hsk-2062042676694003713/HSK5_51002_71-74-e9c288d5-72bb-42ea-aef5-27f417b30b89.png" style="max-width:100%;"><p>一直以来,"80后"这个词儿都含有年轻的味道.随着时间的流逝,我们突然发现,第一批"80后"--1980年出生的人,已经步入而立之年了.</p><p>三十而立的"80后"月收入情况如何?调查显示,就全国范围来看,"1980"们月收入主要集中在3000-5000元,比例为31.2%.其次是集中在1500-3000元,比例也近三成.调查还显示,"1980"们将近五成无房无车,比例为47.9%.</p><p>房子,车子的压力对于"80后"的影响越来越明显.前两年,很少有"80后"会为了公司的薪水,福利等斤斤计较,他们关注工作环境更多.但现在,不少"80后"在办公室里的话题就是围着"钱"打转转.</p><p>专家认为,如果30岁的"80后"现在在职场上还无法收获满足感,他们会对未来失去信心,并因此害怕承担家庭责任.</p>


4、新字段接受完整音频上传到当前试卷section_mapping = SEC_LISTEN的行的question_group.audio_url，如：http://www.hkbvvtb.com:9000/hsk/audio/3232344/hsk-2094694693766500353/HSK1-H11112-8bbd8cb7-7c52-4557-ae6e-2a7ea2b2c14c.mp3
可以在图片和excel上传完成后再绑定音频。
