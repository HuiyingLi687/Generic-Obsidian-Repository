# 音频上传自动绑定题目实现方案

## 一、文件名规则定义

### 规则格式

```
试卷来源_题号.ext
```

| 组成部分 | 示例值 | 对应数据库字段 |
|---|---|---|
| 试卷来源 | `HSK2_H21003`、`HSK1_H12001`、`HSKK初级_H71000` | `exam_paper.source` |
| 题号 | `1`、`15`、`26` | `question.number` |
| 扩展名 | `.mp3`、`.wav`、`.ogg` | 入库，仅用于 MIME 识别 |

### 示例文件名

| 文件名 | 解析结果 | 对应数据库 |
|---|---|---|
| `HSK2_H21003_1.mp3` | source=HSK2_H21003，题号=1 | exam_paper.source = "HSK2_H21003" |
| `HSK1_H123001_15.mp3` | source=HSK1_H123001，题号=15 | exam_paper.source = "HSK1_H123001" |
| `HSKK初级_H71000_26.mp3` | source=HSKK初级_H71000，题号=26 | exam_paper.source = "HSKK初级_H71000" |

### 数据库中 source 字段的实际值

根据业务现状，`exam_paper.source` 字段已包含"等级+试卷编号"的组合，格式如下：

| source 值 | 含义 |
|---|---|
| `HSK1_H123001` | HSK1 级别，试卷编号 H123001 |
| `HSK2_H21003` | HSK2 级别，试卷编号 H21003 |
| `HSK3_H31001` | HSK3 级别，试卷编号 H31001 |
| `HSKK初级_H71000` | HSKK 初级，试卷编号 H71000 |

## 三、处理流程

```
POST /file/uploadSingleVoice (files[])
       │
       ▼
┌───────────────────────────────────────────┐
│ 步骤1：遍历文件数组                       │
│   • 对每个文件依次执行以下步骤             │
│   • 单文件上传：files 长度为 1            │
│   • 批量上传：files 长度 > 1              │
└───────────────────────────────────────────┘
       │
       ▼
┌───────────────────────────────────────────┐
│ 步骤2：基础校验（单文件）                  │
│   • 文件非空、文件名非空                   │
│   • MIME 识别（audio/mpeg 等）             │
└───────────────────────────────────────────┘
       │
       ▼
┌───────────────────────────────────────────┐
│ 步骤3：文件名解析（单文件）                │
│   • 正则匹配：^(.+)_(\d+)\.\w+$           │
│   • 提取：source = 第1组（试卷来源）       │
│         number = 第2组（题号）             │
│   • 解析失败 → 返回提示，不影响上传        │
└───────────────────────────────────────────┘
       │
       ▼
┌───────────────────────────────────────────┐
│ 步骤4：查询试卷和题目                     │
│   • 查 exam_paper：WHERE source = ?       │
│   • 查 question：WHERE paper_id = ?       │
│                  AND number = ?           │
│   • 防覆盖检查：如果 audio_url 已有值      │
│     则跳过上传，返回 existingAudioUrl     │
└───────────────────────────────────────────┘
       │
       ▼
┌───────────────────────────────────────────┐
│ 步骤5：上传到 MinIO（单文件）              │
│   • 生成路径：audio/{userId}/hsk-{paperId}/│
│              {原文件名-uuid}.ext           │
│   • 返回 URL                              │
└───────────────────────────────────────────┘
       │
       ▼
┌───────────────────────────────────────────┐
│ 步骤6：自动绑定题目（单文件）              │
│   • 更新 question.audio_url = URL         │
└───────────────────────────────────────────┘
       │
       ▼
返回结果：[
  { url, bound, paperId, questionId, message },  // 第1个文件
  { url, bound, paperId, questionId, message },  // 第2个文件
  ...
]
```

## 四、正则表达式设计

```java
// 文件名匹配正则：试卷来源_题号.ext
// source 支持包含下划线（如 HSK2_H21003），题号为纯数字
String pattern = "^(.+)_([0-9]+)\\.[a-zA-Z0-9]+$";
//                 ↑         ↑
//           试卷来源      题号

// 示例匹配：
// HSK2_H21003_1.mp3     → group1=HSK2_H21003, group2=1
// HSK1_H123001_15.mp3   → group1=HSK1_H123001, group2=15
// HSKK初级_H71000_26.mp3 → group1=HSKK初级_H71000, group2=26
```

**正则说明**：
- `^(.+)_`：匹配试卷来源部分，`.+` 表示任意字符（包含下划线），直到最后一个下划线前
- `([0-9]+)`：匹配题号，纯数字
- `\.[a-zA-Z0-9]+$`：匹配扩展名，以点号开头的字母数字组合

### 5.1 音频文件名解析器（新增工具类）

```java
// AudioFileNameParser.java - 新增文件
package com.hsktreasure.manage.util;

import java.util.regex.Matcher;
import java.util.regex.Pattern;

/**
 * 音频文件名解析器
 * 解析规则：试卷来源_题号.ext
 * 示例：HSK2_H21003_1.mp3
 * 
 * 其中 试卷来源 对应 exam_paper.source 字段（已包含等级+编号）
 */
public class AudioFileNameParser {

    /**
     * 正则：试卷来源_题号.ext
     * source 支持下划线（如 HSK2_H21003），题号为纯数字
     */
    private static final Pattern PATTERN = 
        Pattern.compile("^(.+)_([0-9]+)\\.[a-zA-Z0-9]+$");
    
    /**
     * 解析文件名
     * @param filename 原始文件名（含扩展名）
     * @return ParseResult
     */
    public static ParseResult parse(String filename) {
        if (filename == null || filename.isEmpty()) {
            return ParseResult.failed();
        }
        Matcher matcher = PATTERN.matcher(filename);
        if (!matcher.matches()) {
            return ParseResult.failed();
        }
        return ParseResult.success(
            matcher.group(1),    // source（试卷来源，如 HSK2_H21003）
            matcher.group(2)     // number（题号）
        );
    }
    
    /**
     * 解析结果
     */
    public static class ParseResult {
        private boolean success;
        private String source;    // 试卷来源（对应 exam_paper.source）
        private String number;    // 题号（对应 question.number）
        
        private ParseResult(boolean success, String source, String number) {
            this.success = success;
            this.source = source;
            this.number = number;
        }
        
        public static ParseResult success(String source, String number) {
            return new ParseResult(true, source, number);
        }
        
        public static ParseResult failed() {
            return new ParseResult(false, null, null);
        }
        
        // getter
        public boolean isSuccess() { return success; }
        public String getSource() { return source; }
        public String getNumber() { return number; }
    }
}
```

#### 5.2.2 Service 层（AudioUploadService）

```java
// AudioUploadService.java - 新增文件
package com.hsktreasure.manage.service;

public interface AudioUploadService {
    /**
     * 上传单题音频并自动绑定题目（支持单文件/批量）
     */
    List<UploadResult> uploadSingleVoice(MultipartFile[] files);
}
```

```java
// AudioUploadServiceImpl.java - 新增文件
package com.hsktreasure.manage.service.impl;

@Service
public class AudioUploadServiceImpl implements AudioUploadService {

    @Autowired
    private MinIOConfig minIOConfig;
    @Autowired
    private ExamPaperMapper examPaperMapper;
    @Autowired
    private QuestionMapper questionMapper;

    @Override
    public List<UploadResult> uploadSingleVoice(MultipartFile[] files) {
        if (files == null || files.length == 0) {
            throw new BusinessException(ErrorCode.FILE_UPLOAD_NULL_ERROR);
        }

        List<UploadResult> results = new ArrayList<>(files.length);
        for (MultipartFile file : files) {
            UploadResult result = processSingleFile(file);
            results.add(result);
        }
        return results;
    }

    /**
     * 处理单个音频文件（上传 + 解析 + 绑定）
     */
    private UploadResult processSingleFile(MultipartFile file) {
        // 1. 基础校验
        if (file == null || file.isEmpty()) {
            UploadResult result = new UploadResult();
            result.setBound(false);
            result.setMessage("文件为空，跳过");
            return result;
        }
        String filename = file.getOriginalFilename();
        if (StringUtils.isBlank(filename)) {
            UploadResult result = new UploadResult();
            result.setBound(false);
            result.setMessage("文件名为空，跳过");
            return result;
        }

        // 2. 解析文件名（规则：试卷来源_题号.ext，如 HSK2_H21003_1.mp3）
        AudioFileNameParser.ParseResult parseResult = AudioFileNameParser.parse(filename);
        if (!parseResult.isSuccess()) {
            UploadResult result = new UploadResult();
            result.setBound(false);
            result.setMessage("文件名格式不符合规则（试卷来源_题号.ext），跳过");
            return result;
        }

        // 3. 查试卷：根据 source 定位（source 已包含等级+编号）
        ExamPaper paper = examPaperMapper.selectOne(
            Wrappers.<ExamPaper>lambdaQuery()
                .eq(ExamPaper::getSource, parseResult.getSource())
        );
        if (paper == null) {
            UploadResult result = new UploadResult();
            result.setBound(false);
            result.setMessage("未找到对应试卷（source=" + parseResult.getSource() + "）");
            return result;
        }

        // 4. 查题目：根据 paperId + number 定位
        Question question = questionMapper.selectOne(
            Wrappers.<Question>lambdaQuery()
                .eq(Question::getPaperId, paper.getId())
                .eq(Question::getNumber, parseResult.getNumber())
        );
        if (question == null) {
            UploadResult result = new UploadResult();
            result.setBound(false);
            result.setPaperId(paper.getId());
            result.setMessage("未找到对应题目（number=" + parseResult.getNumber() + "）");
            return result;
        }

        // 5. 检查题目的 audio_url 是否已存在（防覆盖）
        if (StringUtils.isNotBlank(question.getAudioUrl())) {
            UploadResult result = new UploadResult();
            result.setBound(false);
            result.setPaperId(paper.getId());
            result.setQuestionId(question.getId());
            result.setExistingAudioUrl(question.getAudioUrl());
            result.setMessage("该题目已绑定音频（URL=" + question.getAudioUrl() + "），跳过本次上传");
            return result;
        }

        // 6. 获取 MIME
        String mime = AudioMimeUtil.getAudioMime(file);
        if (mime == null) {
            UploadResult result = new UploadResult();
            result.setBound(false);
            result.setPaperId(paper.getId());
            result.setQuestionId(question.getId());
            result.setMessage("文件格式不支持，跳过");
            return result;
        }

        // 7. 上传到 MinIO
        Long userId = 3232344L;
        String finalName = "audio/" + userId + "/hsk-" + paper.getId() + "/" + dealFilename(filename);
        String url;
        try {
            url = MinIOUtils.uploadFile(
                    minIOConfig.getBucketName(),
                    finalName,
                    file.getInputStream(),
                    true,
                    mime
            );
        } catch (Exception e) {
            UploadResult result = new UploadResult();
            result.setBound(false);
            result.setPaperId(paper.getId());
            result.setQuestionId(question.getId());
            result.setMessage("上传失败：" + e.getMessage());
            return result;
        }

        // 8. 绑定到题目
        question.setAudioUrl(url);
        questionMapper.updateById(question);

        UploadResult result = new UploadResult();
        result.setUrl(url);
        result.setBound(true);
        result.setPaperId(paper.getId());
        result.setQuestionId(question.getId());
        result.setMessage("音频已自动绑定到题目");
        return result;
    }

    private String dealFilename(String fileName) {
        String suffixName = fileName.substring(fileName.lastIndexOf("."));
        String fName = fileName.substring(0, fileName.lastIndexOf("."));
        String uuid = UUID.randomUUID().toString();
        return fName + "-" + uuid + suffixName;
    }
}
```

### 5.5 音频 MIME 类型识别（AudioMimeUtil）

> **说明**：由于不同浏览器、操作系统、上传工具发送的音频文件 MIME 类型可能不同（如 `.wav` 文件可能发送 `audio/wav`、`audio/x-wave`、`application/octet-stream` 等），`AudioMimeUtil.getAudioMime()` 采用模糊匹配 + 扩展名降级的策略来兼容各种情况。

```java
// AudioMimeUtil.java - 修改（原有代码为精确 switch case 匹配）
public static String getAudioMime(MultipartFile file) {
    if (file == null || file.isEmpty()) {
        return null;
    }
    
    String contentType = file.getContentType();
    String originalFilename = file.getOriginalFilename();
    
    // 优先按 contentType 模糊匹配
    if (contentType != null) {
        contentType = contentType.toLowerCase();
        if (contentType.contains("mpeg") || contentType.contains("mp3")) {
            return "audio/mpeg";
        }
        if (contentType.contains("wav") || contentType.contains("wave")) {
            return "audio/wav";
        }
        if (contentType.contains("ogg")) {
            return "audio/ogg";
        }
        if (contentType.contains("flac")) {
            return "audio/flac";
        }
        if (contentType.contains("midi") || contentType.contains("mid")) {
            return "audio/midi";
        }
    }
    
    // 降级按文件扩展名匹配
    if (originalFilename != null) {
        String lowerName = originalFilename.toLowerCase();
        if (lowerName.endsWith(".mp3")) {
            return "audio/mpeg";
        }
        if (lowerName.endsWith(".wav")) {
            return "audio/wav";
        }
        if (lowerName.endsWith(".ogg")) {
            return "audio/ogg";
        }
        if (lowerName.endsWith(".flac")) {
            return "audio/flac";
        }
        if (lowerName.endsWith(".mid") || lowerName.endsWith(".midi")) {
            return "audio/midi";
        }
    }
    
    return null;
}
```

**兼容的 MIME 类型**：

| 文件扩展名 | 兼容的 MIME 类型 |
|---|---|
| `.mp3` | `audio/mpeg`、`audio/mp3`、`audio/x-mpeg` 等 |
| `.wav` | `audio/wav`、`audio/x-wav`、`audio/x-wave`、`application/octet-stream`（通过扩展名识别）等 |
| `.ogg` | `audio/ogg`、`application/ogg` 等 |
| `.flac` | `audio/flac`、`application/flac` 等 |
| `.mid` / `.midi` | `audio/midi`、`audio/x-midi` 等 |

## 七、注意事项

1. **试卷必须已导入**：音频绑定前，必须先通过 Excel 导入试卷和题目，否则找不到对应记录
2. **题号必须匹配**：`question.number` 字段存储的题号需与文件名中的题号完全一致（如都是 `"1"`、`"15"`）
3. **不影响上传**：文件名解析失败或未找到题目时，上传仍会成功，只是不自动绑定
4. **跳过已绑定**（防覆盖）：如果题目 `audio_url` 已有值，则跳过本次上传和绑定，不上传到 MinIO、不更新数据库；返回 `existingAudioUrl` 字段供前端提示
5. **事务控制**：建议将"上传 + 绑定"放在同一个事务中，确保数据一致性
6. **大小写敏感**：`exam_paper.source` 的值需与文件名中的试卷来源完全一致
7. **扩展名校验**：上传时仍需通过 `AudioMimeUtil` 校验文件真实格式，防止恶意文件
8. **source 字段格式**：`exam_paper.source` 已包含等级+编号（如 `HSK2_H21003`），文件名中的试卷来源部分需与其完全匹配
9. **接口职责分离**：`uploadVoice` 仅上传返回 URL，`uploadSingleVoice` 上传并自动绑定，前端按需选择
10. **单/批量一体**：`uploadSingleVoice` 统一使用 `files` 数组参数，传 1 个即为单文件，传多个即为批量，返回 `List<UploadResult>` 与输入一一对应
11. **批量容错**：批量上传时单个文件失败不影响其他文件，每个文件独立返回结果

## 十、完整数据流总结

```
1. 用户准备 1 个或多个音频文件，命名为：{试卷来源}_{题号}.mp3
2. 调用 POST /file/uploadSingleVoice 上传（files 数组，支持单/批量）
3. 遍历每个文件，依次执行：
   a. 解析文件名 → source, number
   b. 上传到 MinIO → 生成 URL
   c. 查询 exam_paper WHERE source=? → 得到 paperId
   d. 查询 question WHERE paper_id=? AND number=? → 得到 questionId
   e. 更新 question.audio_url = URL
4. 返回 List<UploadResult>（与输入文件一一对应）
5. 考试时：exam-service 根据 question.audio_url 播放音频
```
