## 三、逐个组件规范

每个组件只记「和别的组件不一样的地方」：材料、作答动作、提交门槛。

### F01 汉字拼音配对

- **布局**：左栏汉字（带序号 1/2/3），右栏拼音（带字母 A/B/C），两栏等宽卡片。
- **交互**：先点左侧，再点右侧，成对即锁定；提交前可重选。**不要求拖拽**。
- **材料**：纯文字。无音频、无图片。
- **覆盖形式**：`L3/pair_match`、`L5/pair_match`（汉字与拼音配对，3 组）。

### F02 录音词语配对

- **布局**：与 F01 同构，左栏是「播放录音 1 / 播放录音 2」按钮，右栏是词语（拼音 + 释义，如 `yīqǐ 一起`）。
- **交互**：先播左侧音频，再点右侧词语；对应关系一旦成立即高亮。
- **材料**：左音频 + 右文字。**音频是作答材料，不是题干**。
- **覆盖形式**：`L2/audio_pair`（录音与词语配对，3 组）。

> F01 与 F02 差一个材料维度（文字 / 音频），UI 可复用同一套配对骨架，用 `leftMaterial` 切换。

### F03 点词组句

- **布局**：上方作答区（虚线框，占位文案「句子显示在这里」），下方词块横排池。
- **交互**：点词块 → 追加到作答区；点已选词块 → 撤回。**必须全部用完才能提交**。
- **材料**：词块文字，可带拼音开关。
- **覆盖形式**：`L3/word_order`、`L4/word_order`、`L5/word_order`、`L5/audio_word_order`、`L6/fixed_word_order`（点词组句，无选项数，记「—」）。

> `L5/audio_word_order` 是「先听后组句」，材料多一段音频，其余同 F03。

### F04 共享问答匹配

- **布局**：3 个问句纵向排列，每句右侧一个 `?` 按钮；下方提示「第 N 小题 · 选择对应选项」。
- **交互**：点 `?` → 弹出**同一组共享回答**；逐小题各选一个；**小题必须全部作答才能提交本题组**。禁止复用选项时，把选项改配到别的小题会释放原匹配（PRD A06 第 4 条）。
- **材料**：纯文字，带拼音。
- **覆盖形式**：`L1/shared_question_answer`、`L2/match`、`L3/match`（共享问答匹配，选项数 2／3）。

### F05 听音选图

- **布局**：顶部一个「播放录音」按钮，下方 2 列图片卡片（带 A/B 角标）。
- **交互**：播音频 → 点一张图；可改选。
- **材料**：音频 + 图片选项。**图片是选项，不是题干**。
- **覆盖形式**：`L1/listen_picture_2`、`L1/picture_choice_2`（看图选文字，反向）、`L2/listen_picture_group`、`L3/listen_picture_group`（录音匹配**共享**图片）、`L2/picture_match`（句子匹配共享图片）。

> 共享图片的三种形式（`listen_picture_group` / `picture_match`）本质是「一组图片被多小题复用」，需要在 F05 上加 `sharedOptions` 开关。

### F06 看词选录音

- **布局**：题干区一块灰底卡片显示词语（如 `汉语`），下方 2×2 选项，每个选项是「播放选项 A/B/C/D」按钮。
- **交互**：先看词，再逐个试听选项，选中即高亮。
- **材料**：文字题干 + 音频选项。与 F05 正好互为镜像。
- **覆盖形式**：`L1/word_to_audio_4`、`L1/picture_audio_options_2`（看图选录音）、`L4/audio_options`、`L6/audio_options`（看词选录音，4 选项）。

### F07 看图用词造句

- **布局**：题干「根据图片，用"介绍"写一句话」→ 大图 → 必用词标签 → 单行输入框「你的表达」。
- **交互**：输入一句话；主按钮是「保存作品」，不是「提交答案」。
- **材料**：图片 + 必用词（1 个）+ 文本输入。
- **覆盖形式**：`L4/picture_write`（看图用词造句）。

### F08 给词写短文

- **布局**：题干含字数要求（约 80 字）→ 5 个必用词标签横排 → 多行输入框（占位「在这里输入中文……」）。
- **交互**：五个词**必须全部使用**，顺序不限；主按钮「保存作品」。
- **材料**：必用词列表 + 长文本输入，无图片。
- **覆盖形式**：`L5/word_write`（五词短文写作）、`L6/summary_write`（阅读后缩写，无给词、有原文）。

> F07 / F08 是同一组件的两个档位：单句 vs 成篇。差别在输入框高度、必用词数量、字数要求，可以共用一个 `writeInput` 组件加 `mode: sentence | passage`。

### F09 句段排序

- **布局**：上方作答区（「句子显示在这里」），下方句子卡片纵向排列（每张是一整句，不是词块）。
- **交互**：点句子 → 追加成段；点已选 → 撤回。与 F03 同机制，只是**排序单位从词块变成句子**。
- **材料**：句子文字，3–4 句。
- **覆盖形式**：`L4/sentence_order`（句段排序）。

### F10 选句填空

- **布局**：顶部标「共同材料」，正文中带 `(1)(2)` 空格序号；下方「把数字放回问题中 · 第 1/2 小题」；再下方是共享选项池。
- **交互**：逐个空位从**同一组共享选项**里选；选项数 5（比 HSK4 的 4 多 1）。
- **材料**：共同短文 + 空格 + 共享选项。
- **覆盖形式**：`L6/sentence_cloze`（选句填空，5 项）、`L1/shared_word_bank`／`L2/cloze_group`／`L3/cloze_group`／`L4/cloze_group`（共享词库填空，3 项）、`L2/cloze`／`L3/cloze`（句中选词，4 项）、`L5/passage_cloze`（短文逐空选择，4 项）、`L6/combo_cloze`（组合选词填空，4 项）、`L3/character`（双空字形选填，2 项）。

> 这是覆盖最广的组件（10 个形式）。四个可变点是：空格数、选项是否共享、选项数（2–5）、材料是句子还是短文。

### F11 共同听力材料

- **布局**：顶部「共同材料 · 博物馆服务采访 · 第 1/2 小题」→「播放共同录音」按钮 →「播放问题」按钮 → 4 个文字选项。
- **交互**：共同录音与小题音频**是两个独立播放键**；小题共用同一段录音。
- **材料**：共享音频 + 单题音频 + 文字选项。
- **覆盖形式**：`L6/listen_interview`（听采访回答问题）、`L6/listen_consistent`（听后选择一致表述）、`L6/passage_question_4`／`L5/passage_consistency_4`／`L4/passage_question_4`／`L4/question_only_4`（短文理解四选一）、`L3/passage_question_3`（短文理解三选一）。

> F11 严格说**不是作答组件，是材料容器**：它管的是 `question_group` 级的共享音频/共享正文，作答动作还是「单选」。落在数据上就是 `question_group.audio_url` + `question_group.passage`，不要为它单开一个 `layout`。

## 四、11 个组件之外的 40 个形式（没有独立原型）

| 缺失族 | 形式数 | 涉及界面名称 |
|---|---:|---|
| 文字／拼音单选 | 22 | 听音选择(8)、选拼音(5)、听音选拼音(2)、对话缺句二选一(1)、韵母选填(1)、声母选填(1)、听音选韵母(1)、听音选声母(1)、听音选声调(1)、病句辨析(1) |

| 录音作答 | 7 | 听后重复(6)、朗读拼音(1) |

**这三类不是「没做」，是复用了其他页面**：
- 判断与文字单选 → 复用考试侧的 `choice` / `judge` 组件，原型图里没单画。
- 录音作答 → 复用 `A08 录音练习` 页面（状态机：未录音 → 授权/录音中 → 停止 → 回放/重录 → 保存录音 → 作品反馈）。

所以真正要新建的只有 F01–F10 这 10 个作答组件；F11 是材料容器，判断/单选/录音走已有实现。

## 五、界面布局控制 `course_layout`

**全面提升课用自己的一套，不与考试侧 `exam_layout`、练习侧 `question.layout` 混用。**

三条理由：
1. 考试侧 `exam_layout` 8 值是按**判分口径**划的（`multiChoice`、`passageChoice` 都在服务判分），提升课不判分，口径不同。
2. 练习侧 `question.layout` 有 8 个老值 + 48% NULL，且 practice-service 4 处依赖，动它就是改存量。
3. 三套若共用常量，任何一方加值或改名都会牵连另外两处；独立后各自演进。

`course_layout` 只描述**渲染形态**，不描述题型内容。13 个值：

| 值               | 渲染形态          | 组件        | 渲染要点                      |
| --------------- | ------------- | --------- | ------------------------- |
| `choice`        | 文字/拼音单选项纵向    | 文字单选      | 选项 2–4 项，可带拼音开关           |
| `judge`         | 两项判断          | 判断        | 选项固定两项，沿用已配置文案            |
| `imageChoice`   | 图片作选项         | F05       | 2 列图片卡片 + ABC 角标          |
| `audioChoice`   | 音频作选项         | F06       | 选项是「播放选项 A/B/C/D」按钮       |
| `pair`          | 左右两栏配对（文字↔文字） | F01       | 左序号 1/2/3，右字母 A/B/C，点左再点右 |
| `audioPair`     | 音频↔文字配对       | F02       | 左栏播放键，右栏词语 + 拼音           |
| `sharedAnswer`  | 共享回答逐小题匹配     | F04       | 多问句共用一组回答，全答完才能提交         |
| `order`         | 词块排序成句        | F03       | 点词块追加，点已选撤回，必须用完          |
| `sentenceOrder` | 句子排序成段        | F09       | 同 `order` 机制，排序单位是句子      |
| `blankFill`     | 共同材料 + 逐空共享选项 | F10       | 空位带 `(1)(2)` 序号，选项池整组共享   |
| `sentenceWrite` | 单句输入          | F07       | 单行输入 + 必用词标签              |
| `passageWrite`  | 成篇输入          | F08       | 多行输入 + 必用词 + 字数要求         |
| `record`        | 录音作答          | 听后重复 / 朗读 | 走 A08 录音练习状态机             |

分族看：单选/判断 4 值、配对 3 值、排序 2 值、填空 1 值、写作 2 值、录音 1 值。

**材料不占 `course_layout`。** 共享音频（F11）、共享图片（F05 变体）、共享正文（F10）都是**题组级材料**，落在题组记录上；单题仍用上表的作答形态。若把「共享」写进 layout，同一题组里的小题就会失去自己的作答形态。

> 库表未建，字段名先记 `course_layout`，最终随建表一起定。全套 13 值须一次建齐，避免后续按等级补值。

## 六、待确认

1. **组件数量口径**：PRD 6.1 写「40 类交互组件」，附录 B 按界面名称去重是 **41**。差 1 个，要么是合并了某两个名称，要么是 PRD 笔误。
2. **F08 是否含缩写**：`L6/summary_write`（阅读后缩写）是「有原文、无给词」，和「给词写短文」材料不同。现在同挂 `passageWrite`，是否要拆子档 `passageWrite.summary`？
3. **共享选项能否复用**：F04 的规则是「禁止复用时改配会释放原匹配」，但 81 个形式里没有字段声明「本形式是否允许复用」，现在只能按形式 ID 硬编码。
