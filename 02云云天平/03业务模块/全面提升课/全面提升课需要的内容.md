# 全面提升课需要的内容

`course_layout` 只描述**选项排布 + 作答动作**，不描述材料媒介、篇幅长短、选项数量、左右栏形态。**7 个值**：

| 值              | 作答动作        | 渲染要点                                                                                          |
| -------------- | ----------- | --------------------------------------------------------------------------------------------- |
| `choice`       | 从选项里选一项（单列） | 选项纵向一项一行、占满整行：选项是成句文本、音频播放卡，或若干空共用一份词库时走这里；有材料时材料与题干同屏                                        |
| `choiceGrid`   | 从选项里选一项（双列） | 选项两列栅格，左 A 右 B 逐行填充，2 项时即左右各一；只用于选项短到能并排的形式——对/错、单字、词、拼音、声母韵母声调、图片；对应原型 `optionLayout:"grid"` |
| `pair`         | 左右两栏配对      | 左序号 1/2/3，右字母 A/B/C，点左再点右；左右栏是文字还是音频由字段决定                                                     |
| `sharedAnswer` | 共享选项逐小题匹配   | 整组共用一组选项（文字或图片），逐小题作答，全部完成才整题提交                                                               |
| `order`        | 排序          | 点选追加、点已选撤回、必须用完；排序单位是词块或整句                                                                    |
| `write`        | 文本写作        | 单行或多行输入 + 必用词 + 字数要求                                                                          |
| `record`       | 录音作答        | 走录音练习状态机（A08）                                                                                 |

合并记录：`imageChoice` + `audioChoice` → `choice`，`audioPair` → `pair`，`sentenceWrite` + `passageWrite` → `write`，`judge` → `choiceGrid`。`choice` 与 `choiceGrid` 同属「选一项」，差别只在**选项排几列**，所以拆成两个值而不是一个带参数的值。

**列数与材料无关**：共享听力材料的两题（Q73 `choiceGrid`、Q74 `choice`）都要同时渲染共享音频与单题音频两个播放键；材料有无、材料是一层还是两层，不影响 layout 取值。

### 四类差异不进 layout

它们都不改变用户的操作方式，改由字段表达：

| 差异    | 靠什么区分                                                             | 同一 layout 下的例子                                  |
| ----- | ----------------------------------------------------------------- | ----------------------------------------------- |
| 选项媒介  | `option_content` / `option_image_urls` / `option_audio_urls` 哪列有值 | 选拼音（文字）、听音选图（图片）、看词选录音（音频）都是 `choiceGrid`——媒介只决定选项里放什么 |
| 选项数量  | 选项列的条目数                                                          | 判断题 2 项（对/错）、听音选词 4 项、声母选填 4 项都是 `choiceGrid`；短文理解 3/4 项是 `choice` |
| 配对栏媒介 | 左栏 / 右栏存的是文字还是音频 URL                                              | 汉字与拼音配对、录音与词语配对都是 `pair`                       |
| 篇幅长短  | 字数上下限                                                             | 看图用词造句（单句）与五词短文、阅读后缩写（成篇）都是 `write`            |
