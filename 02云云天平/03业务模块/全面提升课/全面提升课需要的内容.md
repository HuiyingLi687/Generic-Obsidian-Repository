# 全面提升课需要的内容

`course_layout` 只描述**作答动作**，不描述材料媒介、篇幅长短、选项数量、左右栏形态。**6 个值**：

| 值              | 作答动作      | 渲染要点                                                                                           |
| -------------- | --------- | ---------------------------------------------------------------------------------------------- |
| `choice`       | 从选项里选一项   | 选项 2–5 项；2 项时左右两列并排（判断题走这里），3 项以上纵向列表；媒介由哪列有值决定；有材料时材料与题干同屏；共享听力材料（Q73、Q74）需同时渲染共享音频与单题音频两个播放键 |
| `pair`         | 左右两栏配对    | 左序号 1/2/3，右字母 A/B/C，点左再点右；左右栏是文字还是音频由字段决定                                                      |
| `sharedAnswer` | 共享选项逐小题匹配 | 整组共用一组选项（文字或图片），逐小题作答，全部完成才整题提交                                                                |
| `order`        | 排序        | 点选追加、点已选撤回、必须用完；排序单位是词块或整句                                                                     |
| `write`        | 文本写作      | 单行或多行输入 + 必用词 + 字数要求                                                                           |
| `record`       | 录音作答      | 走录音练习状态机（A08）                                                                                  |

合并记录：`imageChoice` + `audioChoice` → `choice`，`audioPair` → `pair`，`sentenceWrite` + `passageWrite` → `write`，`judge` → `choice`。

### 四类差异不进 layout

它们都不改变用户的操作方式，改由字段表达：

| 差异    | 靠什么区分                                                             | 同一 layout 下的例子                         |
| ----- | ----------------------------------------------------------------- | -------------------------------------- |
| 选项媒介  | `option_content` / `option_image_urls` / `option_audio_urls` 哪列有值 | 听音选择（文字）、听音选图（图片）、看词选录音（音频）都是 `choice` |
| 选项数量  | 选项列的条目数                                                          | 判断题 2 项（「对」「错」两列并排）与四选一 4 项（纵向）都是 `choice` |
| 配对栏媒介 | 左栏 / 右栏存的是文字还是音频 URL                                              | 汉字与拼音配对、录音与词语配对都是 `pair`               |
| 篇幅长短  | 字数上下限                                                             | 看图用词造句（单句）与五词短文、阅读后缩写（成篇）都是 `write`    |

`judge` 并入 `choice` 的依据：判断题也是「从选项里选一项」，只是选项固定为「对」「错」两项、按两列排。选项文案与数量都是数据，不是作答动作，所以不单独立值。

> 合并后判断题的 `answer` 建议与 `choice` 统一存选项键（对=A、错=B），不要一套存「对/错」一套存「A/B」；选项文案放 `option_content`，判分只比对键。
