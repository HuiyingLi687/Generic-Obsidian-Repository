## 三、逐个组件规范

每个组件只记「和别的组件不一样的地方」：材料、作答动作、提交门槛。

### F01 汉字拼音配对

- **布局**：左栏汉字（带序号 1/2/3），右栏拼音（带字母 A/B/C），两栏等宽卡片。
- **交互**：先点左侧，再点右侧，成对即锁定；提交前可重选。**不要求拖拽**。
- **材料**：纯文字。无音频、无图片。
- **覆盖形式**：`L3/pair_match`、`L5/pair_match`（汉字与拼音配对，3 组）。

### F02 录音词语配对

- **布局**：与 F01 同构，左栏是「播放录音 1 / 播放录音 2」按钮，右栏是词语（拼音 + 释义，如 `yīqǐ 一起`）。
- **交互**：先播左侧音频，再点右侧词语；对应关系一旦成立即高亮。
- **材料**：左音频 + 右文字。**音频是作答材料，不是题干**。
- **覆盖形式**：`L2/audio_pair`（录音与词语配对，3 组）。

> F01 与 F02 差一个材料维度（文字 / 音频），UI 可复用同一套配对骨架，用 `leftMaterial` 切换。**两者共用 `pair`**，不因左栏是文字还是音频而拆成两个值。

### F03 点词组句

- **布局**：上方作答区（虚线框，占位文案「句子显示在这里」），下方词块横排池。
- **交互**：点词块 → 追加到作答区；点已选词块 → 撤回。**必须全部用完才能提交**。
- **材料**：词块文字，可带拼音开关。
- **覆盖形式**：`L3/word_order`、`L4/word_order`、`L5/word_order`、`L5/audio_word_order`、`L6/fixed_word_order`（点词组句，无选项数，记「—」）。

> `L5/audio_word_order` 是「先听后组句」，材料多一段音频，其余同 F03。

### F04 共享问答匹配

- **布局**：3 个问句纵向排列，每句右侧一个 `?` 按钮；下方提示「第 N 小题 · 选择对应选项」。
- **交互**：点 `?` → 弹出**同一组共享回答**；逐小题各选一个；**小题必须全部作答才能提交本题组**。禁止复用选项时，把选项改配到别的小题会释放原匹配（PRD A06 第 4 条）。
- **材料**：纯文字，带拼音。
- **覆盖形式**：`L1/shared_question_answer`、`L2/match`、`L3/match`（共享问答匹配，选项数 2／3）。

### F05 听音选图

- **布局**：顶部一个「播放录音」按钮，下方 2 列图片卡片（带 A/B 角标）。
- **交互**：播音频 → 点一张图；可改选。
- **材料**：音频 + 图片选项。**图片是选项，不是题干**。
- **覆盖形式**：`L1/listen_picture_2`、`L1/picture_choice_2`（看图选文字，反向）、`L2/listen_picture_group`、`L3/listen_picture_group`（录音匹配**共享**图片）、`L2/picture_match`（句子匹配共享图片）。

> 共享图片的三种形式（`listen_picture_group` / `picture_match`）本质是「一组图片被多小题复用」，需要在 F05 上加 `sharedOptions` 开关。

### F06 看词选录音

- **布局**：题干区一块灰底卡片显示词语（如 `汉语`），下方 2×2 选项，每个选项是「播放选项 A/B/C/D」按钮。
- **交互**：先看词，再逐个试听选项，选中即高亮。
- **材料**：文字题干 + 音频选项。与 F05 正好互为镜像。
- **覆盖形式**：`L1/word_to_audio_4`、`L1/picture_audio_options_2`（看图选录音）、`L4/audio_options`、`L6/audio_options`（看词选录音，4 选项）。

### F07 看图用词造句

- **布局**：题干「根据图片，用"介绍"写一句话」→ 大图 → 必用词标签 → 单行输入框「你的表达」。
- **交互**：输入一句话；主按钮是「保存作品」，不是「提交答案」。
- **材料**：图片 + 必用词（1 个）+ 文本输入。
- **覆盖形式**：`L4/picture_write`（看图用词造句）。

### F08 给词写短文

- **布局**：题干含字数要求（约 80 字）→ 5 个必用词标签横排 → 多行输入框（占位「在这里输入中文……」）。
- **交互**：五个词**必须全部使用**，顺序不限；主按钮「保存作品」。
- **材料**：必用词列表 + 长文本输入，无图片。
- **覆盖形式**：`L5/word_write`（五词短文写作）、`L6/summary_write`（阅读后缩写，无给词、有原文）。

> F07 / F08 是同一组件的两个档位：单句 vs 成篇。差别在输入框高度、必用词数量、字数要求，可以共用一个 `writeInput` 组件加 `mode: sentence | passage`。**两者共用 `write`**，篇幅靠字数上下限约束，不靠枚举值区分。

### F09 句段排序

- **布局**：上方作答区（「句子显示在这里」），下方句子卡片纵向排列（每张是一整句，不是词块）。
- **交互**：点句子 → 追加成段；点已选 → 撤回。与 F03 同机制，只是**排序单位从词块变成句子**，两者共用 `order`。
- **材料**：句子文字，3–4 句。
- **覆盖形式**：`L4/sentence_order`（句段排序）。

### F10 选句填空

- **本质**：**它就是单选**。不是独立作答形态，差别只在「一屏里同时显示材料与题干」。落到 `course_layout` 是 `choice`，材料走题组级字段。
- **布局**：上方材料区（短文或对话，空位带 `(1)(2)` 序号）→ 题干「第 1/2 小题」→ 选项列表。
- **交互**：每个空独立选一个选项，选中可改；共享选项时同一组选项被多小题复用。
- **材料**：共同短文/句子；空位由材料标注，选项属于单题。
- **覆盖形式**：`L6/sentence_cloze`（选句填空，5 项）、`L1/shared_word_bank`／`L2/cloze_group`／`L3/cloze_group`／`L4/cloze_group`（共享词库填空，3 项）、`L2/cloze`／`L3/cloze`（句中选词，4 项）、`L5/passage_cloze`（短文逐空选择，4 项）、`L6/combo_cloze`（组合选词填空，4 项）、`L3/character`（双空字形选填，2 项）。

> 覆盖 10 个形式，但**不需要新 layout**。可变点只有三个：材料是句子还是短文、选项数（2–5）、选项是否题组共享。这三项都是内容属性，不是渲染形态。

### F11 共同听力材料

- **layout**：`choice`。**它是一道单选题**，只是多挂了一层共享听力材料。
- **布局**：顶部「共同材料 · 博物馆服务采访 · 第 1/2 小题」→「播放共同录音」按钮 →「播放问题」按钮 → 4 个文字选项。
- **交互**：共同录音与小题音频是**两个独立播放键**——前者整组共用，后者每题一条；作答仍是四选一，选中可改。
- **材料**：题组级共享录音（整组共用）+ 题目级单题音频（每题一条）+ 文字选项。两层音频都挂在题上，不构成独立 layout。
- **覆盖形式（7 个）**：
  - **双层音频（2 个）**：`L6/listen_interview`（听采访回答问题）、`L6/listen_consistent`（听后选择一致表述）——题组一条共同录音 + 每题一条问题音频。
  - **共享文字材料（5 个）**：`L6/passage_question_4`／`L5/passage_consistency_4`／`L4/passage_question_4`／`L4/question_only_4`（短文理解四选一）、`L3/passage_question_3`（短文理解三选一）——同一渲染形态，但材料层是 `passage` 不是音频，**不画播放键**。

> **数据落点不用新建字段**：共享录音 → `question_group.audio_url`（整组一条），单题音频 → `question.audio_url`（每题一条）。两列都已存在且在服役——现网 `question.audio_url` 有值 2,540 / 13,574 题，`question_group.audio_url` 有值 521 / 1,034 组。所以 `course_layout` 就是 `choice`；渲染时只要题组带共享音频，就在题干上方多画一个「播放共同录音」键。

## 四、11 个组件之外的 40 个形式（没有独立原型）

| 缺失族 | 形式数 | 涉及界面名称 |
|---|---:|---|
| 文字／拼音单选 | 22 | 听音选择(8)、选拼音(5)、听音选拼音(2)、对话缺句二选一(1)、韵母选填(1)、声母选填(1)、听音选韵母(1)、听音选声母(1)、听音选声调(1)、病句辨析(1) |
| 判断 | 11 | 音文判断(5)、图音判断(2)、听力判断(2)、图文判断(1)、短文判断(1) |
| 录音作答 | 7 | 听后重复(6)、朗读拼音(1) |

**这三类不是「没做」，是复用了其他页面**：
- 判断与文字单选 → 复用考试侧的 `choice` / `judge` 组件，原型图里没单画。
- 录音作答 → 复用 `A08 录音练习` 页面（状态机：未录音 → 授权/录音中 → 停止 → 回放/重录 → 保存录音 → 作品反馈）。

所以真正要新建的只有 **4 个**作答形态：`pair`（F01/F02）、`order`（F03/F09）、`sharedAnswer`（F04）、`write`（F07/F08）。F05/F06 就是单选（只是选项是图片或音频），F10/F11 也是单选（F11 多一层共享音频），判断、录音都走已有实现。

## 五、界面布局控制 `course_layout`

**全面提升课用自己的一套，不与考试侧 `exam_layout`、练习侧 `question.layout` 混用。**

三条理由：
1. 考试侧 `exam_layout` 8 值是按**判分口径**划的（`multiChoice`、`passageChoice` 都在服务判分），提升课不判分，口径不同。
2. 练习侧 `question.layout` 有 8 个老值 + 48% NULL，且 practice-service 4 处依赖，动它就是改存量。
3. 三套若共用常量，任何一方加值或改名都会牵连另外两处；独立后各自演进。

`course_layout` 只描述**作答动作**，不描述材料媒介、篇幅长短、左右栏形态。**7 个值**：

| 值 | 作答动作 | 组件 | 渲染要点 |
| --- | --- | --- | --- |
| `choice` | 从选项里选一项 | 文字单选、F05、F06、F10、F11 | 选项 2–5 项，媒介由哪列有值决定；有材料时材料与题干同屏；F11 需同时渲染共享音频与单题音频两个播放键 |
| `judge` | 两项判断 | 判断 | 选项固定两项，沿用已配置文案 |
| `pair` | 左右两栏配对 | F01、F02 | 左序号 1/2/3，右字母 A/B/C，点左再点右；左右栏是文字还是音频由字段决定 |
| `sharedAnswer` | 共享回答逐小题匹配 | F04 | 多问句共用一组回答，全答完才能提交 |
| `order` | 排序 | F03、F09 | 点选追加、点已选撤回、必须用完；排序单位是词块或整句 |
| `write` | 文本写作 | F07、F08 | 单行或多行输入 + 必用词 + 字数要求 |
| `record` | 录音作答 | 听后重复、朗读 | 走 A08 录音练习状态机 |

**三类差异不进 layout，改由字段表达：**

| 差异 | 靠什么区分 | 同一 layout 下的例子 |
| --- | --- | --- |
| 选项媒介 | `option_content` / `option_image_urls` / `option_audio_urls` 哪列有值 | 听音选择（文字）、听音选图（图片）、看词选录音（音频）都是 `choice` |
| 配对栏媒介 | 左栏 / 右栏存的是文字还是音频 URL | 汉字↔拼音（F01）与录音↔词语（F02）都是 `pair` |
| 篇幅长短 | 字数上下限 | 看图用词造句（单句）与五词短文、阅读后缩写（成篇）都是 `write` |

这三类差异都**不改变用户的操作方式**（都是点选、配对、输入），所以不各占一个枚举值。合并记录：`imageChoice` + `audioChoice` → `choice`，`audioPair` → `pair`，`sentenceWrite` + `passageWrite` → `write`。

**F11 落在 `choice`**——它同样是单选题，独特点是要同时挂两层音频：题组级共享材料 + 题目级单题音频。`choice` 渲染时若检测到题组有共享音频，就在题干上方多渲染一个「播放共同录音」键。

分族看：选择/判断 2 值、配对 2 值、排序 1 值、写作 1 值、录音 1 值。

**材料不占 `course_layout`，但双层材料要能被 `choice` 渲染出来。** F10 是「材料与题干同屏」的例子，F11 是「两层音频同屏」的例子：共享录音挂题组（`question_group.audio_url`），单题音频挂题（`question.audio_url`），两列现成。`course_layout` 只回答「怎么作答」（都是 `choice`），材料层数由数据决定，不由 layout 决定。

> 库表未建，字段名先记 `course_layout`，最终随建表一起定。全套 7 值须一次建齐，避免后续按等级补值。

2. **`write` 是否拆子档**：`L6/summary_write`（阅读后缩写）是「有原文、无给词」，和「给词写短文」材料不同，但作答动作同样是成篇输入。现同挂 `write`，若确认需要区分，建议用子档 `write.summary` 而不是新增枚举值。
3. **共享选项能否复用**：F04 的规则是「禁止复用时改配会释放原匹配」，但 81 个形式里没有字段声明「本形式是否允许复用」，现在只能按形式 ID 硬编码。
